# ❄️ Snowball-Battle（2.5D 像素风打雪仗）

一款可直接部署并在 **GitHub Pages** 游玩的 2.5D 像素风打雪仗小游戏，同时适配 **电脑端（键鼠）** 与 **手机端（虚拟摇杆 + 拖拽瞄准触控）**。

## 🎮 在线游玩
👉 GitHub Pages：`https://gdhjdsydh.github.io/Snowball-Battle/`

## ✨ 核心特色
- **2D 像素 × 2.5D 立体纵深**：动态 Y-Sort 遮挡排序、大树树冠穿行自动淡化、Z 轴雪球抛物线与地面投影、雪地脚印、多层视差飘雪与矮障碍（倒木）飞跃机制。
- **核心战斗系统**：
  - 血量 **5 颗心**，雪球伤害 **1 颗心**，受击后精确 **30 帧（0.5s）无敌时间**。
  - 雪球上限 **5 颗**，在雪堆旁按住 **`R` / 装填按钮** 持续 **1.5 秒**即可补满雪球。
  - 按 **`Z` / 冲刺按钮** 向前无敌冲刺（冷却 **3 秒**）。
- **四位 Q 版像素主角与专属技能**：
  1. **尤妮安娜（Unianna）— 时间冻结**：冻结万物 5 秒，期间投出的雪球定格在空中，解冻瞬间同时高速射出（CD 20 秒）。
  2. **苏米（Kuki）— 曲奇饼干**：品尝曲奇立即恢复 1 颗心（CD 8 秒）。
  3. **白雪喵都（Miyako）— 寒冰护盾**：召唤寒冰魔法防护罩，5 秒内免疫一切伤害并弹开雪球（CD 20 秒）。
  4. **小苏（Tessel）— 拔刀斩**：近战挥刀斩击（1 颗心伤害，并可斩碎敌方雪球），5 秒内击中敌人 3 次（不限同一目标）进入 10 秒冷却。
- **丰富可拾取道具与五色魔法书**：
  - 🩹 **绷带**：立即恢复 1 颗心生命值。
  - 🍦 **冰淇淋**：短时间内移动速度大幅提升（+42%，持续 7 秒）。
  - ☕ **热可可**：立即补满雪球并将当前冲刺与技能冷却缩减 50%。
  - 📕 **绯红魔典（五发散弹）**：8 秒内每次投掷齐射 5 颗扇形散弹雪球（仅消耗 1 颗雪球）。
  - 📘 **蔚蓝魔典（无限连射）**：8 秒内投掷不消耗雪球且射速加快。
  - 🟪 **紫晶魔典（极寒减速）**：9 秒内雪球命中目标施加 4 秒 50% 寒霜减速。
  - 📙 **鎏金魔典（幸运暴击）**：9 秒内雪球拥有 45% 概率触发 2 心暴击伤害。
  - 📗 **翠绿魔典（疾风穿透）**：8 秒内雪球飞行更迅猛并可穿透多名敌人。
- **双模式游玩**：
  - **冒险模式（5 关 + BOSS 战）**：深入巨大雪地地图，迎战雪精灵、狂暴雪怪与冰霜术士，最终挑战双阶段 BOSS「极寒霜王」。
  - **混战模式（4 人大乱斗）**：任选 1 位角色主控，其余 3 位由具备角色专属战术的 AI 接管，支持「生存淘汰赛」与「2 分钟积分赛」。

## 🕹️ 操作说明
- **电脑端**：`WASD` / 方向键移动 · 鼠标瞄准 + `左键` 投掷 · `Z` 冲刺 · 雪堆旁长按 `R`（1.5 秒）补雪 · `X` / `E` / `右键` 释放技能 · `Esc` / `P` 暂停。
- **手机端**：左侧虚拟摇杆移动 · 右侧按钮支持轻点自动瞄准或按住拖动精准瞄准投掷、冲刺、技能与长按装填。

## 🛠️ 本地开发
```bash
npm install
npm run dev
npm run build
```
